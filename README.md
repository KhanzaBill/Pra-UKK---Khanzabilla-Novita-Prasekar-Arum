# Sistem Pemesanan Makanan Berbasis QR Code

Tugas Pra-UKK — Khanzabilla Novita Prasekar Arum (Kelas XII PPLG 1 SMK Negeri 8 Semarang)

## Deskripsi
Sistem pemesanan makanan berbasis QR code untuk pelanggan dine-in maupun take away di "Yummy Chicken", agar pelanggan bisa memesan secara mandiri tanpa melalui kasir.

## Fitur Utama
- Scan QR code & pilih tipe pesanan (Dine-In/Take Away)
- Lihat menu, tambah ke keranjang, checkout
- Dashboard kasir/admin untuk kelola menu & pantau pesanan real-time
- Rekap laporan penjualan otomatis

## Struktur Folder
- `analisis/` — dokumen analisis, flowchart, ERD, context diagram, DFD, perencanaan biaya
- `src/` — source code frontend & backend
- `database/` — struktur database 
- `testing/` — dokumen hasil pengujian
